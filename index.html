한 줄 결론 — 국내 개발 채용의 중심은 여전히 Java/Spring 백엔드(전체의 36%)입니다. 그다음으로 큰 직군은 AI 엔지니어(21%)로, 프론트엔드 공고의 2.5배입니다. AI 직군 밖에서 LLM·에이전트를 요구하는 공고는 12~32% 수준이고, AI 코딩도구는 프론트엔드·모바일 쪽에서 먼저 요건으로 등장하고 있습니다.

8개 직군 평균은 직군별 공고 수로 가중한 값입니다.

  • 백엔드는 Java 천하 — 백엔드 공고의 57%가 Java, 32%가 Spring을 요구합니다. Python은 19%, Node.js는 10%, Kotlin은 8%입니다.
  • AI 엔지니어는 이제 "LLM 엔지니어" — AI 엔지니어 공고의 45%가 LLM, 38%가 에이전트, 31%가 RAG를 언급합니다. PyTorch(25%)보다 많습니다.
  • 프론트엔드 표준은 React + TypeScript — React 63%, TypeScript 44%, Next.js 26%, Vue 15%입니다.
  • 인프라는 Kubernetes + AWS + IaC — Kubernetes 56%, AWS 50%, Terraform 29%입니다. GCP(20%)와 Azure(16%)는 한참 뒤입니다.
  • 크로스플랫폼은 Flutter가 React Native보다 앞섭니다 — 크로스플랫폼 공고에서 Flutter 55%, React Native 44%입니다. 모바일 공고 전체 중 크로스플랫폼 직무가 40%를 차지합니다.
  • 신입 문은 AI·모바일이 가장 넓습니다 — 신입 지원 가능 비율이 AI 엔지니어 32%, 모바일 네이티브 33%, 크로스플랫폼 32%로 가장 높습니다. 인프라(19%)와 백엔드(20%)는 가장 좁습니다.

어디서 모았나

국내 채용 플랫폼 27곳에 올라온 개발 직군 공고를 모았습니다. 같은 공고가 여러 플랫폼에 올라온 경우가 많아서 26%(4건 중 1건)는 중복을 합쳐 한 건으로 셌습니다. 한 플랫폼만 보면 놓치는 공고와, 여러 플랫폼에 중복으로 잡히는 공고를 함께 정리한 결과입니다.

직군별 공고 규모

게시 중인 공고 수입니다. 막대 길이는 8개 직군 공고를 모두 더한 값에서 각 직군이 차지하는 비중입니다.

백엔드 하나가 8개 직군 공고의 36%를 차지합니다. AI 엔지니어(약 2,400건)는 프론트엔드(약 970건)와 풀스택(약 1,400건)을 합친 것보다 많습니다. 모바일은 네이티브와 크로스플랫폼을 합쳐도 약 430건으로 가장 작습니다.

직군별 기술 스택

직군마다 본문을 받은 공고에서 각 기술이 언급된 비율입니다. 상위 12개만 표시했고, 모든 차트가 같은 눈금(0~100%)을 씁니다. 각 차트 옆(휴대폰에서는 아래)에 직군 요약을 붙였습니다.

직군별 AI 요구

LLM·에이전트·RAG·MCP·생성형 AI를 언급한 공고와, AI 코딩도구 이름을 직접 적은 공고의 비율입니다.

AI 엔지니어를 빼면 데이터 엔지니어(32%)가 가장 높고, 인프라·풀스택·백엔드·프론트엔드는 15~21% 사이입니다. AI 코딩도구는 반대로 크로스플랫폼(14%), 프론트엔드(13%), 모바일 네이티브(13%) 같은 클라이언트 직군에서 많이 언급되고, 백엔드(4%)와 데이터(5%)는 적습니다.

직군별 경력 조건

신입(경력 무관 포함)이 지원 가능한 공고와 7년 이상 경력을 요구하는 공고의 비율입니다. 괄호 안은 최소 경력의 중앙값입니다.

AI 엔지니어는 최소 경력 중앙값이 2년으로 가장 낮고 신입 지원 가능 비율도 높습니다. 신규 수요가 크고 경력자 풀이 얇은 직군이라서 그렇습니다. 7년 이상 요구는 풀스택(19%), 데이터(18%), 백엔드(17%) 순으로 높고, 모바일 네이티브(7%)가 가장 낮습니다.
